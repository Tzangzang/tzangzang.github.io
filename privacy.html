Privacy Policy

Last updated: 21 November 2026

Review Gaming 24h ("the app") is a private tool used by the owner of the YouTube channel Review Gaming 24h to publish videos to that channel. This policy explains what data the app uses.

Who can use the app

Only the channel owner. The app is not offered to the public and no other user signs in to it.

Google user data the app accesses

With the channel owner's consent, the app uses these YouTube API scopes:

  • youtube.upload: to upload videos to the owner's channel.
  • youtube: to set titles, descriptions, tags, thumbnails and publish times of those videos, and to confirm which channel is connected.

The app does not read, collect or store viewers' personal data, comments, or any data from other channels or accounts.

How data is stored

The OAuth access and refresh tokens are stored only on the channel owner's own computer, in a private file readable by that user. They are never sent to any server other than Google's.

Sharing

The app does not sell, share or transfer Google user data to anyone. Data obtained through YouTube API Services is used only to publish and manage the owner's own videos.

Revoking access

The channel owner can revoke the app's access at any time at myaccount.google.com/permissions, after which the stored tokens stop working; the local token file can then be deleted.

YouTube API Services

The app uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
